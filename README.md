# Golestan

A static showcase website for Golestan, built with pure HTML and CSS.

## Viewing the site

Open `index.html` in any browser. No build step or server required.

## Structure

- `index.html` — homepage
- `css/style.css` — all styles
- `images/` — logos and product images

## Editing

- Pages are plain HTML files in the project root.
- Styles live in `css/style.css`.
- Images go in `images/` and are referenced with relative paths.
